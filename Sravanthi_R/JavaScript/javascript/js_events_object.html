Js Event Object

Event object - properties

  • type: The type of event (e.g., "click")
  • target: The element that triggered the event
  • currentTarget: The element the event listener is attached to
  • bubbles: Boolean indicating if the event bubbles up through the DOM
  • cancelable: Boolean indicating if the events default action can be prevented
  • defaultPrevented: Boolean indicating if preventDefault() has been called
  • eventPhase: The phase of event propagation (capturing, at target, bubbling)
  • timeStamp: The time the event was created
