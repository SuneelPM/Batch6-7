# HTML Concepts

## Core Fundamentals
- **Document structure** — `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`
- **Metadata** — `<meta>` tags (charset, viewport, description, Open Graph)
- **Linking resources** — `<link>`, `<script>`, `<style>`
- **Comments** — `<!-- -->`

---

## Text & Content
- Headings (`h1`–`h6`), paragraphs, line breaks
- Inline elements — `<span>`, `<strong>`, `<em>`, `<b>`, `<i>`, `<mark>`, `<small>`, `<sub>`, `<sup>`
- Preformatted text — `<pre>`, `<code>`, `<kbd>`, `<samp>`
- Quotations — `<blockquote>`, `<q>`, `<cite>`, `<abbr>`

---

## Lists
- Unordered (`<ul>`), ordered (`<ol>`), description (`<dl>`, `<dt>`, `<dd>`)
- Nested lists

---

## Links & Navigation
- Anchor tag (`<a>`) — `href`, `target`, `rel`, `download`
- Fragment identifiers (`#id`)
- `mailto:` and `tel:` links

---

## Images & Media
- `<img>` — `src`, `alt`, `width`, `height`, `loading="lazy"`
- Responsive images — `srcset`, `sizes`, `<picture>`
- `<figure>` and `<figcaption>`
- `<video>` and `<audio>` — `controls`, `autoplay`, `loop`, `muted`, `<source>`
- `<iframe>` — embedding external content
- `<canvas>` and `<svg>` (basics)

---

## Tables
- `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`
- `colspan`, `rowspan`
- `<caption>`, `scope` for accessibility

---

## Forms
- `<form>` — `action`, `method`, `enctype`
- Input types — `text`, `email`, `password`, `number`, `tel`, `url`, `date`, `time`, `color`, `range`, `file`, `checkbox`, `radio`, `hidden`
- `<label>`, `<textarea>`, `<select>`, `<option>`, `<optgroup>`
- `<button>` — `type` (submit, reset, button)
- `<fieldset>` and `<legend>`
- `<datalist>` for autocomplete
- Form attributes — `required`, `disabled`, `readonly`, `placeholder`, `autofocus`, `autocomplete`, `pattern`, `min`, `max`, `step`

---

## Semantic HTML
- Layout elements — `<header>`, `<footer>`, `<main>`, `<nav>`, `<aside>`, `<section>`, `<article>`
- `<details>` and `<summary>`
- `<time>`, `<address>`, `<progress>`, `<meter>`
- Choosing `<div>` vs. semantic tags

---

## Accessibility (a11y)
- ARIA roles and attributes — `role`, `aria-label`, `aria-labelledby`, `aria-describedby`, `aria-hidden`
- Landmark roles
- Tab order and `tabindex`
- Skip navigation links
- Alt text best practices
- Focus management

---

## Global Attributes
- `id`, `class`, `style`, `title`, `lang`, `dir`
- `data-*` custom attributes
- `hidden`, `contenteditable`, `draggable`, `spellcheck`
- `translate`

---

## HTML5 APIs (entry-level awareness)
- Drag and Drop API
- Geolocation API
- Web Storage (`localStorage`, `sessionStorage`)
- History API
- Intersection Observer (used alongside HTML)

---

## Performance & Best Practices
- `defer` and `async` on `<script>`
- Lazy loading images and iframes
- Preloading resources — `<link rel="preload">`, `<link rel="prefetch">`
- Favicon and web app manifest
- Proper heading hierarchy for SEO

---

## SEO Basics
- Semantic structure for crawlers
- `<title>` and `<meta name="description">`
- Open Graph and Twitter Card meta tags
- Canonical links (`<link rel="canonical">`)
- Structured data (schema.org basics)

---

Mastering these will give you a rock-solid HTML foundation and make your CSS and JavaScript work much more effective.
