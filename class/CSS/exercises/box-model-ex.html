CSS Box Model Quiz

Master padding, borders, and margins using content-box calculations and coding techniques.

Part 1: Calculations & Concepts

1 Total Width Calculation

Calculate the total horizontal space occupied by this element: 

.box {
  width: 300px;
  padding: 20px;
  border: 5px solid black;
  margin: 15px;
}
View Solution

$$\text{Total Width} = 300\text{px} + (20\text{px} \times 2) + (5\text{px} \times 2) + (15\text{px} \times 2)$$

$$300 + 40 + 10 + 30 = 380\text{px}$$

Result: $380\text{px}$

2 Padding Shorthand

If an element is styled with padding: 10px 25px;, what are the specific values for each side?

View Solution
  • Top & Bottom: $10\text{px}$
  • Left & Right: $25\text{px}$
3 Vertical Margin Collapse

Box A has margin-bottom: 40px;. Box B (immediately below) has margin-top: 25px;. What is the actual vertical gap between them?

View Solution

Due to margin collapse, the gap is equal to the maximum of the two adjacent margins:

$$\text{Gap} = \max(40\text{px}, 25\text{px}) = 40\text{px}$$

4 Total Height Calculation

Calculate the total vertical space occupied by this element: 

.box {
  height: 150px;
  padding-top: 10px;
  padding-bottom: 30px;
  border-top: 2px solid red;
  border-bottom: 0px;
  margin-top: 20px;
  margin-bottom: 20px;
}
View Solution

$$\text{Total Height} = 150\text{px} + 10\text{px} + 30\text{px} + 2\text{px} + 0\text{px} + 20\text{px} + 20\text{px}$$

Result: $232\text{px}$

5 Border Shorthand Identification

Which side has a border width of $20\text{px}$ in: border-width: 5px 10px 15px 20px;?

View Solution

Order: Top ($5\text{px}$), Right ($10\text{px}$), Bottom ($15\text{px}$), Left ($20\text{px}$).

6 Negative Margins

If an element has margin-left: -30px;, in which direction does the element move?

View Solution

The element is pulled $30\text{px}$ to the left (potentially overlapping the container or previous siblings).

7 Padding vs Margin

Which layer is located inside the border and shows the background color?

View Solution

Padding.

8 Centering

What property value pair is used for centering a block element horizontally?

View Solution

margin: 0 auto;

9 Percentage Padding

Padding percentages are relative to what property of the parent?

View Solution

The Width of the parent container.

10 Layer Order

List the box model parts from innermost to outermost.

View Solution

Content $\rightarrow$ Padding $\rightarrow$ Border $\rightarrow$ Margin.

Part 2: Writing CSS

11 Shorthand Border

Write a single line of CSS for a $3\text{px}$ dashed blue border on all sides.

View Solution 
border: 3px dashed blue;
12 Specific Padding

Write padding for: Top $20\text{px}$, Right $10\text{px}$, Bottom $5\text{px}$, Left $0$.

View Solution 
padding: 20px 10px 5px 0;
13 Top Border Only

Set a solid red $4\text{px}$ border only on the top side.

View Solution 
border-top: 4px solid red;
14 Mirror Margins

Set top/bottom margins to $50\text{px}$ and left/right to $0$ using 2 values.

View Solution 
margin: 50px 0;
15 Global Reset

Remove margins and padding from the body.

View Solution 
body {
  margin: 0;
  padding: 0;
}
16 3-Value Margin Shorthand

Write the margin shorthand for the following specifications:

  • Top: $10\text{px}$
  • Left & Right: $20\text{px}$
  • Bottom: $30\text{px}$
View Solution 
margin: 10px 20px 30px;

Note: The 3-value shorthand follows the order: Top | Right & Left | Bottom.

17 Bottom Border Style

Make the bottom border a double line, $5\text{px}$ thick.

View Solution 
border-bottom: 5px double;
18 External Spacing

Add $15\text{px}$ of space between adjacent elements.

View Solution 
margin: 15px;
19 Inner Gutter

Create $10\text{px}$ of space inside a container's border.

View Solution 
padding: 10px;
20 Invisible Border

Create a $10\text{px}$ solid border that is transparent.

View Solution 
border: 10px solid transparent;
