CSS Selectors Masterclass

30 Practical challenges using only Universal, Type, ID, Class, Attribute, and Grouping selectors.

Universal

1. The Global Reset

Write a CSS rule that sets the margin and padding of every single element to 0.

View Solution

  margin: 0;
  padding: 0;
}
