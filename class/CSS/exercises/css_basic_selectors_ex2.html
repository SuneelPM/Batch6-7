CSS Selectors Masterclass

30 Practical coding problems to master basic CSS selectors.

Basic

1. The Universal Selector

Write a CSS rule that sets the margin and padding of every single element on the page to 0.

View Solution 
* {
  margin: 0;
  padding: 0;
}
Basic

2. Paragraph Styling

Select all <p> elements and change their text color to "darkslategray".

View Solution 
p {
  color: darkslategray;
}
ID

3. The Unique Header

Target an element with the ID of main-navigation and set its background color to "navy".

View Solution 
#main-navigation {
  background-color: navy;
}
Class

4. Highlighting Text

Select all elements with the class name highlight and give them a yellow background.

View Solution 
.highlight {
  background-color: yellow;
}
Grouping

5. Multi-Heading Reset

In a single rule, set the font-family of h1, h2, and h3 tags to "Arial".

View Solution 
h1, h2, h3 {
  font-family: Arial, sans-serif;
}
Combinator

6. List Items in Footer

Select all <li> elements that are inside a <footer> tag.

View Solution 
footer li {
  /* styles here */
}
Combinator

7. Direct Children

Select only the <span> elements that are direct children of a <div>.

View Solution 
div > span {
  /* styles here */
}
Combinator

8. Spacing After Headings

Target a <p> element only if it immediately follows an <h2> element.

View Solution 
h2 + p {
  margin-top: 0;
}
Combinator

9. Siblings Down the Line

Select all <img> tags that are siblings of an <h1> and come after it.

View Solution 
h1 ~ img {
  border: 1px solid #ccc;
}
Attribute

10. All Links with Titles

Select every <a> tag that has a title attribute, regardless of its value.

View Solution 
a[title] {
  text-decoration: underline;
}
Attribute

11. Targeting specific inputs

Target all <input> elements with the type attribute exactly equal to "text".

View Solution 
input[type="text"] {
  border-color: blue;
}
Compound

12. Specific Buttons

Select <button> elements that also have the class primary.

View Solution 
button.primary {
  font-weight: bold;
}
Compound

13. The Overlap

Select elements that have both the btn class AND the active class.

View Solution 
.btn.active {
  opacity: 1;
}
Combinator

14. Sidebar Links

Select all links (a) inside an element with the ID sidebar.

View Solution 
#sidebar a {
  color: inherit;
}
Basic

15. Global Font

Select the body and set the base font size to 16px.

View Solution 
body {
  font-size: 16px;
}
Pseudo

16. Interactive Links

Change the color of an <a> tag to "red" when the user hovers over it.

View Solution 
a:hover {
  color: red;
}
Attribute

17. External Links

Select all <a> tags where the href attribute starts with "https".

View Solution 
a[href^="https"] {
  /* styles for secure links */
}
Attribute

18. PDF Links

Select all <a> tags where the href attribute ends with ".pdf".

View Solution 
a[href$=".pdf"] {
  /* add a PDF icon or style */
}
Attribute

19. Internal Mentions

Select all <div> tags whose class contains the word "section" anywhere.

View Solution 
div[class*="section"] {
  padding: 20px;
}
Pseudo

20. The First List Item

Select the very first <li> inside any <ul> and make it bold.

View Solution 
ul li:first-child {
  font-weight: bold;
}
Pseudo

21. The Final Paragraph

Select the last <p> inside a <section> and remove its bottom margin.

View Solution 
section p:last-child {
  margin-bottom: 0;
}
Pseudo

22. Exceptions

Select all <input> tags that are NOT of type "submit".

View Solution 
input:not([type="submit"]) {
  border: 1px solid gray;
}
Pseudo-Element

23. Text Addition

Add the text "Note: " before the content of every element with the class disclaimer using CSS.

View Solution 
.disclaimer::before {
  content: "Note: ";
}
Pseudo

24. Form Validation

Target all <input> elements that have the required attribute.

View Solution 
input:required {
  box-shadow: 0 0 5px red;
}
Pseudo

25. Checkbox Styling

Select checkboxes that are currently checked and change their labels' color (assuming label is a sibling after the input).

View Solution 
input[type="checkbox"]:checked + label {
  color: green;
}
Attribute

26. Language Specifics

Select all elements that are specifically marked with the language "fr" (French).

View Solution 
[lang="fr"] {
  font-style: italic;
}
Compound

27. Container Reset

Reset the padding of all elements that are inside a <div> with the class card.

View Solution 
div.card * {
  padding: 0;
}
Pseudo

28. Empty Containers

Select all <div> elements that have no content at all (no text, no children) and hide them.

View Solution 
div:empty {
  display: none;
}
Pseudo

29. Zebra Stripes

Select every even <tr> (table row) to apply a background color for zebra-striping.

View Solution 
tr:nth-child(even) {
  background-color: #f2f2f2;
}
Attribute

30. Specific Data Attribute

Select elements where the data-info attribute contains the word "urgent" in a space-separated list.

View Solution 
[data-info~="urgent"] {
  border: 2px solid red;
}
