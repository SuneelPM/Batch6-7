#1The Absolute Basics

Beginner

Write a function called executeCallback that takes a function (a callback) as its only argument and immediately executes it.

Input: () => console.log("Hello!")
Expected Output: Logs "Hello!" to the console. 
function executeCallback(callback) {
  // Check if callback is actually a function before executing
  if (typeof callback === 'function') {
    callback();
  }
}

// Usage:
executeCallback(() => {
  console.log("Hello!");
});

#18Build Your Own Map

Beginner

Create a function myMap(array, callback) that behaves exactly like the built-in .map(). It should create a new array, loop over the provided array, apply the callback, and return the new array. 

function myMap(array, callback) {
  const result = [];
  
  for (let i = 0; i < array.length; i++) {
    // Apply callback to each element and push to new array
    const transformedValue = callback(array[i]);
    result.push(transformedValue);
  }
  
  return result;
}

const doubled = myMap([1, 2, 3], num => num * 2);
console.log(doubled); // Output: [2, 4, 6]

#19Build Your Own Filter

Beginner

Create myFilter(array, callback) that mimics .filter(). Return a new array containing only the items where the callback returns a truthy value. 

function myFilter(array, callback) {
  const result = [];
  
  for (let i = 0; i < array.length; i++) {
    // If the callback evaluates to true, keep the item
    if (callback(array[i])) {
      result.push(array[i]);
    }
  }
  
  return result;
}

const isPositive = myFilter([-2, 5, -9, 10], num => num > 0);
console.log(isPositive); // Output: [5, 10]
