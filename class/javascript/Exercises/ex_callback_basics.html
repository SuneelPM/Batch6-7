Core Callback Challenges

Understand callbacks at their most fundamental level using simple parameters, standard loops, math, and custom higher-order structures. No built-in array methods used here!

#1Basic Execution

Beginner

Write a function called runMe that accepts a single callback argument and executes it inside.

Concept:

A callback is a function passed into another function that is invoked after a specific action completes.

Explanation:

In this question, the callback demonstrates basic function-as-data behavior: the host function receives and executes the function argument.

Real-time use case:

This pattern is used in event handling, such as running a button click handler after a user interaction. 

function runMe(callback) {
  // Directly trigger the passed callback function
  callback();
}

// Usage Example:
runMe(() => {
  console.log("Callback executed successfully!");
});

#12Manual Array Iterator

Beginner

Write a custom function customForEach(arr, callback) that uses a standard for loop to iterate through any passed array. Execute the callback on each pass, providing both the current element and its index. Do not use the built-in .forEach() method.

Concept:

Custom iteration callbacks let you mimic built-in array loops using plain control flow.

Explanation:

Instead of relying on built-in helpers, the function explicitly iterates and invokes a callback for each item.

Real-time use case:

This is useful when building compatibility layers or custom traversal behavior. 

function customForEach(arr, callback) {
  for (let i = 0; i < arr.length; i++) {
    // Deliver the element and index manually via standard iteration
    callback(arr[i], i);
  }
}

// Usage Example:
const colors = ["red", "green", "blue"];
customForEach(colors, (color, index) => {
  console.log("Color " + index + " is " + color);
});

#14Robust Fallbacks

Beginner

Create a function safeExecute(callback, fallback). Check if the provided callback is actually a function type. If yes, run it. If it is not provided or not a function, execute the fallback callback.

Concept:

Checking whether a callback is valid before calling it helps avoid errors in flexible APIs.

Explanation:

This example protects code from invalid values and falls back safely when needed.

Real-time use case:

Useful in plugin systems or optional hooks where a callback may not always be supplied. 

function safeExecute(callback, fallback) {
  if (typeof callback === 'function') {
    callback();
  } else {
    fallback();
  }
}

// Usage Example:
safeExecute("not-a-function", () => {
  console.log("Primary failed, fallback executed!");
});

#18Manual Array Finder

Beginner

Create findInArray(arr, checkFn, onFound, onNotFound). Use a manual for loop to traverse the array. For each item, evaluate checkFn(item). If it returns true, immediately call onFound(item) and end the loop. If the loop completes without finding anything, call onNotFound().

Concept:

This uses a callback predicate to find the first array item that matches a condition.

Explanation:

The function loops manually and chooses the success or failure callback based on the search result.

Real-time use case:

Helpful for search operations that trigger a handler when a matching item is located. 

function findInArray(arr, checkFn, onFound, onNotFound) {
  for (let i = 0; i < arr.length; i++) {
    if (checkFn(arr[i])) {
      onFound(arr[i]);
      return; // Stop function execution once found
    }
  }
  onNotFound();
}

// Usage Example:
const values = [3, 5, 11, 7];
findInArray(
  values, 
  num => num > 10,
  (item) => console.log("Found matching: " + item), // Executes
  () => console.log("No match found")
);

Explanation:

The function delegates handling to an admin callback or a regular user callback depending on the role.
