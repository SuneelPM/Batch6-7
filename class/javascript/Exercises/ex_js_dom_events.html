Dynamic Background Switcher

Write code to listen to click events on a button. When clicked, it must swap the background color of a container div to a random pastel shade.

Goal: Change container color on click.

Event Type: "click"

Formula: `hsl(${Math.random() * 360}, 70%, 85%)`

Starter HTML

<button id="colorBtn">Change Color</button>
<div id="colorBox" class="w-24 h-24"></div>

Live Demo Sandbox

Reveal Solution & Explanation 
// Select elements from DOM
const colorBtn = document.getElementById('colorBtn');
const colorBox = document.getElementById('colorBox');

// Add the click listener
colorBtn.addEventListener('click', () => {
  // Generate random pastel shade
  const randomColor = `hsl(${Math.random() * 360}, 70%, 85%)`;
  
  // Update styling
  colorBox.style.backgroundColor = randomColor;
});

Pedagogical Insight:

The click event triggers reliably across all input devices (touch screens, keyboards when focusing the button and hitting Enter/Space, and normal mice). Modifying CSS properties using style.backgroundColor updates inline CSS which carries high styling specificity.

Real-time Search Filter

Build interactive index filter tools. Read keystroke updates and toggle css classes to hide list items that do not contain matching text.

Goal: Toggle visibility flags across many items during input.

Reveal Solution & Explanation 
const searchInput = document.getElementById('search');
const items = document.querySelectorAll('.item');

searchInput.addEventListener('input', (event) => {
  const query = event.target.value.toLowerCase();
  
  items.forEach(item => {
    const text = item.textContent.toLowerCase();

    }
  });
});

Pedagogical Insight:

Copy Trigger Interception

Listen for copy actions inside a target element. When triggered, block the default behavior to append a custom copyright attribution notice to the user's clipboard selection.

Goal: Modify dynamic clipboard assets during copy operations.

Event: "copy"

Starter HTML

<p id="article">Copy this text.</p>

Live Demo Sandbox

Highlight & copy this text!

✅ Attribution appended on copy!

Reveal Solution & Explanation 
const article = document.getElementById('article');

article.addEventListener('copy', (event) => {
  // Capture highlighted selection
  const selectedText = window.getSelection().toString();
  const modifiedText = `${selectedText}\n\nRead more at Source.`;
  
  // Set modified values in the event clipboard data transfer
  event.clipboardData.setData('text/plain', modifiedText);
  event.preventDefault(); // Required for modifications
});

Pedagogical Insight:

Modifying clipboard content using event.clipboardData.setData inside a `copy` listener is highly secure. This approach is much more reliable than using the modern browser `navigator.clipboard` API, which requires requesting explicit user permissions before writing data.

Event Propagation Stop

Manage bubbling flows. Prevent a button click from bubbling up and triggering a click listener on its parent card container.

Goal: Block event bubbling along nested target trees.

Method: Call event.stopPropagation()

Starter HTML

<div id="parentCard">
  <button id="innerBtn">Action</button>

Click outputs show here...

const innerBtn = document.getElementById('innerBtn');

  console.log("Parent card clicked!");
